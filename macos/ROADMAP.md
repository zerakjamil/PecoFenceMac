# Mac developer tools

Implemented in the native Mac port:

- Project actions: Terminal, installed VS Code/Xcode, chosen application, copy path.
- Git branch, changed-path count, ahead/behind footer; local queries only.
- Native Quick Look, arrow navigation, Return to open, Command-C to copy.
- Saved workspaces, menu and keyboard switching, display profile restoration.
- Optional portal filters for build and dependency directories.
- Single-click folds, configurable snap reordering, first-click controls.
- Optional hiding of fenced Desktop originals with recovery and restoration.

Future work: launch at login, Shortcuts/App Intents, custom filename/glob filters,
and multi-select. These are not part of the current build.
