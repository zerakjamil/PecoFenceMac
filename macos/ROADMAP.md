# Features for Mac developers

These are proposed features, not capabilities of the current build.

1. **Project actions.** Open a project fence in Terminal, VS Code, Xcode, or a
   chosen editor. Copy the absolute path and show the folder in Finder.
2. **Git status.** Show branch, dirty-file count, and ahead/behind status for a
   repository portal. Refresh with local Git queries and offer a direct editor
   action; never fetch, commit, or push automatically.
3. **Quick Look and keyboard navigation.** Space to preview, arrows to select,
   Return to open, and Command-C to copy. Support native previews for source,
   images, PDFs, and Markdown.
4. **Project workspaces.** Switch saved groups for development, design, and admin
   with a shortcut. Associate layouts with displays and restore them when a
   monitor reconnects.
5. **Developer filters.** Hide `.git`, `node_modules`, `.build`, `target`, and
   generated files in portals. Add optional filename and glob routing to the UI.
6. **Launch at login and Shortcuts.** Add a native login-item toggle and App
   Intents for switching workspaces, creating portals, and toggling Peek.

Suggested order: project actions, Quick Look, developer filters, then Git status
and workspace automation.
